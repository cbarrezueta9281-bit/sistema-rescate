# Sistema de Rescate y Adopción Animal

Prototipo académico de maquetación estructural para un sistema web de control de rescate y adopción animal, desarrollado únicamente con HTML5.

## Estructura del proyecto

- `index.html`: página principal, objetivos y navegación.
- `reportar.html`: formulario semántico con controles y validación nativa HTML5.
- `rescates.html`: tabla accesible con registros ficticios y descripción de estados.

## Características

- Estructura HTML5 válida y uso de etiquetas semánticas.
- Navegación entre las tres páginas.
- Formularios con etiquetas asociadas, campos obligatorios y atributos de validación.
- Tabla con título, encabezados y atributos `scope`.
- Metadatos de idioma y adaptación a dispositivos móviles mediante `meta viewport`.

## Alcance y limitaciones

Este trabajo implementa únicamente la estructura HTML5 solicitada. No utiliza CSS, JavaScript ni conexión a una base de datos. El formulario es demostrativo y no almacena ni transmite reportes. Los registros de la tabla son datos ficticios.

## Validación

Se recomienda comprobar cada archivo con el [Validador HTML del W3C](https://validator.w3.org/nu/).
